현대 자동차 판매실적 자동화 RPA
Brity RPA를 활용하여 사용자가 지정한 브랜드별 판매 데이터를 웹에서 실시간으로 수집하고, 분석 리포트 생성까지 원스톱으로 처리하는 지능형 자동화 시스템을 구축했습니다.

1. 프로젝트 개요
핵심 도구: Brity RPA, AI Automation

주요 기능: 웹 포털 데이터 동적 크롤링, 조건별 데이터 필터링 및 엑셀 자동화

파일: 상세 설계서 | 데이터 샘플

3. 주요 성과 (Key Results)
맞춤형 동적 자동화 구현: 고정된 데이터가 아닌 사용자가 원하는 브랜드별/조건별 맞춤 데이터를 실시간으로 조회하고 추출하는 유연한 자동화 로직 설계

정보 탐색 효율 극대화: 여러 웹 페이지를 일일이 대조하던 수기 검색 방식을 자동화하여 데이터 수집 및 정리 시간 90% 이상 단축

데이터 정합성 및 무결성 보장: 수작업 시 발생하는 브랜드 오선택이나 숫자 기입 오류 등 휴먼 에러를 원천 차단하여 리포트의 신뢰도 확보

비즈니스 인사이트 적시 제공: 복잡한 조회 과정을 간소화하여 의사결정에 필요한 판매 실적 데이터를 필요한 시점에 즉시 생성(On-demand) 가능한 구조 마련
